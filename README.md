# Task 5: Decision Trees and Random Forests

## Objective
To explore tree-based models such as Decision Trees and Random Forests for classification using Scikit-learn.

## Dataset
Used the [Heart Disease Dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset).

## Tools
- Python
- Scikit-learn
- Graphviz
- Pandas, NumPy, Matplotlib

## Tasks Performed
1. Trained a Decision Tree Classifier
2. Visualized the Decision Tree
3. Controlled depth to avoid overfitting
4. Trained a Random Forest Classifier
5. Compared performances
6. Interpreted feature importance
7. Used cross-validation for evaluation

## Results
- Decision Tree Accuracy: ~82%
- Random Forest Accuracy: ~85%
- Feature importance: Age, Cholesterol, MaxHR were most important features

## How to Run
```bash
pip install -r requirements.txt
python task5_decision_tree_random_forest.py
```
